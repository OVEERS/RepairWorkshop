# Правила для RemoteEvent

1. Имя добавляется в `src/shared/RemoteNames.lua`.
2. Клиент → сервер: подписка только через `Net.on(name, interval, handler)`.
3. В обработчике: проверить `typeof` каждого аргумента, затем существование id
   в конфиге, затем наличие у игрока (инвентарь, деньги, заказ).
4. Клиенту не доверяем ни одному числу и ни одной цене: считает сервер.
5. Сервер → клиент: клиент проверяет `typeof` пришедшего значения.
6. Изменение инвентаря и денег только через модуль `Inventory`.
